Expense Tracker

A simple Python expense tracker that runs in the terminal and stores expenses locally in a JSON file.

Features

  • Expense management: add, edit, delete and view expenses
  • Expense analysis: total spending, spending by category, largest expense
  • Budget management: set a budget, see what remains, check if you are over budget

Run it

Install dependencies: python -m pip install -r requirements.txt

Run the tests: python -m pytest -v
